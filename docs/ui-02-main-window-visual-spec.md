## 4. 启动/完成提示（精确到秒）

```text

完成：转换工作已经完成。完成时间是：YYYY-MM-DD HH:MM:SS

```

时间格式：`%04d-%02d-%02d %02d:%02d:%02d`（见 `now_time`）。

## 5. 空/加载/错误状态（Empty/Loading/Error）

- **空状态**：日志框仅首行作者信息。
- **加载中**：开始按钮变「正在转换......」+ 禁用；日志持续追加。
- **错误**：日志追加 `[错误]...` / `[失败]...`；按钮恢复。

## 6. 响应式断点（Responsive）

无响应式——固定 720×470 桌面窗口（`WS_OVERLAPPEDWINDOW` 可缩放但布局不重排）。
